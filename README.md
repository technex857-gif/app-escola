# Sobre o projeto
## O que é o projeto?
**O Notiva App é uma plataforma web criada para facilitar o trabalho dos professores na organização de turmas, no cadastro de alunos e na correção de provas.
O sistema reúne ferramentas para cadastrar alunos, criar gabaritos, registrar avaliações e consultar notas, tornando essas tarefas mais práticas e organizadas.
O professor poderá enviar fotos das provas para que o sistema, após a implementação da leitura de imagens, compare as respostas com o gabarito e apresente a nota, os acertos e os erros. Caso a imagem esteja ilegível, será exibido um aviso.
O aplicativo também permitirá cadastrar vários alunos de uma só vez e organizar informações como série, turno e dias de aula.
Além disso, o professor poderá corrigir provas de diferentes matérias, independentemente da disciplina informada em seu perfil.
O objetivo do projeto é tornar a rotina escolar mais eficiente, com uma interface simples e acessível. A correção automática, o armazenamento online e a segurança das contas ainda precisarão ser implementados para a versão completa.**
## Tecnologias Ultilizadas
**HTML:utilizado para estruturar as páginas, formulários e campos de cadastro do Notiva App.**

**CSS: responsável pelo design do sistema, incluindo cores, fontes, botões, organização dos elementos e adaptação para diferentes telas.**

**JAVASCRIPT: responsável pela interatividade e pela lógica do sistema, permitindo executar ações como validar informações, cadastrar alunos, registrar notas e controlar as funcionalidades da interface.**
## Como funciona e onde "roda"
**O professor poderá acessar sua conta, organizar as turmas, cadastrar alunos individualmente ou em lote e criar gabaritos para as avaliações. Ao registrar uma prova, selecionará a matéria, a turma e o gabarito correspondente e informará o número de chamada do aluno
Quando os recursos de leitura de imagem estiverem implementados, o sistema analisará a foto, comparará as respostas com o gabarito e apresentará a nota, os acertos e os erros. Respostas que não puderem ser identificadas deverão ser conferidas pelo professor.**
## Onde funciona
**A versão web poderá ser acessada por navegadores modernos, como Google Chrome, Microsoft Edge e Firefox, em computadores, tablets e celulares compatíveis.**
